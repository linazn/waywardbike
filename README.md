# Wayward Bike

A world map of mountain bike, road and gravel trips worth the journey, with this week's riding conditions and when to go.
Sister site to Wayward Ski (copied from its code in Nov 2026; shared fixes are copied across by hand).

- `index.html`, `css/app.css`, `js/*.js`: the site (static, no build step)
- `data/destinations.json`: the places, generated by `scripts/build_destinations.py` (edit that, then run it)
- `data/conditions.json`: typical weather by month and this week's riding conditions, from `scripts/update_conditions.py` (runs daily on GitHub Actions)
- `data/stories.json`: "Read more" pages (none yet)

Local preview: `python3 scripts/serve.py` then open http://localhost:8766
